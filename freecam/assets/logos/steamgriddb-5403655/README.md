# Curated Helldivers II logos

Source: [https://www.steamgriddb.com/game/5403655/logos](https://www.steamgriddb.com/game/5403655/logos).

The active collection contains **8 distinct, non-joke design representatives**, reduced from 69 accessible catalog entries / 67 unique files through visual comparison. Recolors, small crop/size/glow variations and localized wordmarks are grouped under one representative. The named game/update banners retain their different wing/skull artwork and subtitles.

**Joke and meme branding is excluded.** Devoid of Content (179765) was removed from the active set after the humor audit. Beddivers (162551), Brasildivers (126993), PSN Login, Heckdivers, Mikudivers and other parody labels were already absent and are explicitly classified as joke/meme exclusions in `curation.json`.

All eight are transparent original PNGs. Their original bytes and color/alpha metadata are unchanged; `contact-sheet.png` is a separate preview.

`manifest.json` preserves source pages, original download URLs, uploader credits, SHA-256 and image metadata for the selected files. `curation.json` records each excluded entry, the visual or humor reason, and the active-set audit.

The full collection (all 67 originals, all 69 catalog records, original contact sheet and reproduction script) remains in `dist/review/logo-collection-originals`. Every original image hash was rechecked during the humor audit. `BACKUP-VERIFIED.json` records the original byte verification. This archive is local review material and is separate from the active asset set.

The SteamGridDB header reports 71 logos; its unauthenticated public catalog exposes 69 and reports hidden assets. No per-asset license or explicit license reference was listed. Attribution is preserved; download availability is not treated as a redistribution license.

War Journalist 0.9.5 embeds tintable geometry for the seven additional designs in `freecam/assets/logo_art.lua`. The existing main stacked wordmark remains at its saved picker index. These choices use the same retained GUI geometry renderer as the crest, so no external texture/material or separate asset installation is needed. The unchanged original PNGs and this attribution remain bundled. `../runtime-manifest.json` records the generated shapes and source hashes.

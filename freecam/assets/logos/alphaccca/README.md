# Alphaccca vector logos

Two original, unchanged SVG files from public gists by [Alphaccca](https://github.com/Alphaccca):

- [Super_Earth.svg source](https://gist.github.com/Alphaccca/71f148c625adf8e46685ff28f4693d5a): white globe, torch and stars emblem; 1320 x 2000 viewBox.
- [HD_Logo.svg source](https://gist.github.com/Alphaccca/5aef6b8c1ef1e7dbe6491a9a64f5f179): black textless skull and wings emblem; 1354 x 146 viewBox.

`manifest.json` preserves author/source links, gist revisions, revision-pinned raw URLs, byte lengths, SHA-256 and SVG dimensions. Both XML documents parse successfully and contain one vector path with no external resources. They were visually rendered for review; no joke/meme branding is present.

No license file or license statement was listed in either public gist. No license is inferred from the separate Figma resource. Its attribution and explicit CC BY 4.0 declaration are recorded separately under `../figma-community-1382854850516388445`.

Raster review previews are separate under `dist/review/additional-vector-logo-preview`; the source SVG bytes here are unchanged. In 0.9.5 the actual Super Earth insignia replaces the old placeholder with tintable geometry embedded in `freecam/assets/logo_art.lua`. The existing saved picker index is retained. No external texture/material is required. `../runtime-manifest.json` records its source hash and generated geometry. The HD_Logo SVG remains credited source reference; the picker already contains distinct wing/skull choices.

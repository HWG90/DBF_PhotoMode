The public resource page explicitly lists [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Retain this creator/source attribution with the artwork. The downloaded vector export is unchanged; its SHA-256 and source node are in `manifest.json`.

The ordinary frame export included an opaque background; it remains only in `dist/review/figma-logo-export-1382854850516388445`. The active source here uses the transparent SVG asset. No joke/meme branding or stratagem icons were added.

The existing browser document was read and exported through the Figma connector. No Figma document was created, duplicated or edited. This is a source asset, not yet a Helldivers texture/material deployment.

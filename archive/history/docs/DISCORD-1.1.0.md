# 🪿 WAR JOURNALIST 1.1.0
### A Helldivers 2 Photo Mode

**THANK YOU to everyone sharing photos, testing and reporting bugs!** 📸

- Passive now uses player-side no aggro instead of continuously scanning enemies. Solo only. **So uh... don't get too comfy.**
- Independent photo camera; removed the ActionCam adapter/dependency.
- Input/camera recovery fixes and bounded Dummy AI work.
- Follow Player moves the whole lighting rig, with cheaper transform-only movement updates.
- Hoverpack restoration-clock and pause-entry fixes retained; no native hover hook.

No-aggro flag tested live; integrated mode/package checks passed. Wider mission, damage/objective and respawn testing still needed. Keep settings/presets/screenshots, deploy matching bundled assets and restart.

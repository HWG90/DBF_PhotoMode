# Archived implementations and history

These files are retained for reference and are currently defunct.

- `legacy-loaders/`: earlier BSL, MDL and LLL entrypoints and packaging.
- `legacy-tools/`: retired deployment, investigation and release-preparation scripts.
- `history/`: previous changelogs, publication records and verification snapshots.
- `research/`: historical platform investigations.

The active runtime is maintained in `freecam/steam51.lua` and its declared modules.
The separate Chef preview remains in `freecam/chef/`. Shared feature models and
fixtures used by the active code remain under `freecam/`.

Archived scripts preserve historical layouts and are not supported build or
installation entrypoints. They may require the original version's directory layout.

# Subject pose catalogue

This build contains **213 static pose frames**. Choose a pose while **Pause entire action** is on; the scene stays paused. Reset restores the original subject pose.

The catalogue covers the authored action region at layer 8, states 72–236, plus the identified emote families in layer 14. It includes entry, hold, interaction and clip variants for cooperative gestures. The audit considered 191 states, included 162 and excluded 29 proven exit, neutral, locomotion or unrelated upper-body states. Repeated clips are represented once.

**213 frames does not mean 213 released emote items.** An exact released-item-to-animation mapping was unavailable. Names such as Salute, High Five and Chest Bump follow known graph events; posture descriptions and `layer/state` labels identify other sampled frames without claiming official item names. These fallback labels also make variants traceable.

Each frame contains the complete authored skeleton pose. Kneeling thumbs-up variants keep their authored legs. Cooperative poses affect only the selected local subject; they do not animate a partner, create props, play audio or trigger gameplay abilities. The first six entries retain their original order.

Offline validation checks all 107 scene nodes and 90 named bones, normalized quaternions, finite transforms and forward-kinematic agreement with the CPU sampler. All 213 entries passed isolated application, hold, switch and restoration fixtures. Six skeleton contact sheets were inspected for obvious malformed frames. Rendered meshes, garments and each individual pose still require in-game visual acceptance.

Reproduce with `py -3 tools/build_subject_pose_frames.py --cache <resource-cache> --catalog tools/subject_pose_catalog.json`; add `--check` to compare generated bytes. The cache is a build input only. The shipped Lua module contains the sampled data and requires no Epic LUT, Link, cache or decoder at runtime.

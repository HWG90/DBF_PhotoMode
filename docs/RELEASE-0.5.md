# War Journalist 0.5 Preview

Free camera/photo mode with solo action pause, native multiplayer gating, slow motion, camera roll/FOV/lock, saved positions, composition tools, logos and a resizable menu. MCM is optional; bindings remain available standalone.

BSL is the recommended main download. MDL is the alternative. Install one package, disable the original ActionCam, and restart the game normally. Import the BSL release through HD2 Arsenal with Bingus Shared Loader v15 or newer.

Default camera lock is L. Slow motion is backslash. Q/E rolls in camera focus and changes tabs in menu focus. WASD selects settings; Enter or Space chooses/edits; numeric typing and right-click reset are supported.

Focus/aperture and scene shader effects are disabled. See KNOWN-ISSUES.md and the included INSTALL.txt.
